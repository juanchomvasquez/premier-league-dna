## Sources and reconciliation

- [Chelsea FC, PL seasons with 20+ goal contributions](https://www.chelseafc.com/en/news/article/chelsea-players-with-20-plus-goal-contributions-in-a-premier-league-season): Lampard, Drogba and Fabregas totals; Hazard goals and assists.
- [Chelsea FC, contemporary 2018/19 season report](https://www.chelseafc.com/en/news/article/europa-league-and-premier-league-stats-in-2018-19): Hazard 32 starts + 5 substitute appearances = 37. The retrospective above lists 31 appearances, conflicting with the contemporary report. We use 37; the Premier League's [2018/19 awards report](https://www.premierleague.com/en/news/1234961) independently supports 37.
- [Liverpool FC, Gerrard's league scoring peak](https://www.liverpoolfc.com/news/first-team/162268-br-gerrard-didn-t-need-words-from-me): 16 league goals in 2008/09.
- [StatMuse, Gerrard 2008/09](https://www.statmuse.com/fc/ask/steven-gerrard-stats-in-2009?l=eu5): 31 appearances. StatMuse lists 9 assists; the indexed current PL career result showed 10 and Statbunker uses yet another count. Withhold assists until definitions and the source discrepancy can be reconciled. Do not combine providers' assist numbers or infer a resolved value.
- [Premier League, Scholes Hall of Fame profile](https://www.premierleague.com/es/news/1653178): 2002/03 was his scoring peak, with 14 goals.
- [StatMuse, Scholes 2002/03](https://www.statmuse.com/fc/ask?q=paul+scholes+stats+2002%2F03): 33 appearances and 3 assists. Attribute this snapshot; the PL article supports the goals and selection criterion, not the season assists.
- [Premier League statistics coverage](https://www.premierleague.com/en/stats/clarification): wider statistics begin in 2006/07. This does not prove that every later metric is available or equivalently defined.

## What changed in the dashboard

Sourced season facts appear by default next to the selected synthetic performance.
The invented purple overlay is now an explicit checkbox, off by default. Historical
season totals are never placed on the per-100-action-sequence radar. The source check
date, source links, selection rationale and limitations are visible in the card and
the Historical source coverage expander. No numerical historical index is supplied.

The synthetic generator and all underlying action counts remain unchanged. It still
generates independent action scenarios rather than a complete possession-consistent
match. Nothing about these fact cards establishes realistic match event rates.

## Required before historical style matching

For each reference, acquire source-permitted compatible event metrics and exposure
minutes, document event definitions, and calculate rates in the SAME units for the
synthetic performance and historical season. Box arrivals are not touches in the box;
assists are not chances created; pass completion is not progressive passing. Do not
infer those mappings. Review role and era effects, small-sample behaviour and ranking
stability before publishing an overall index. No career-high composites or unsupported
values may be used to fill coverage gaps.

## Install this update

Unzip `premier-league-dna-all-25-seasons.zip`. It contains just:

- `app.py` (replace the existing root file)
- `pl_dna/historical.py` (replace this inside the existing `pl_dna` folder)

At the repository root, choose **Add file → Upload files** and drag the extracted
`app.py` and `pl_dna` folder together. Do not delete the existing folder or upload the
ZIP itself. Commit once. If Streamlit displays an old version or import error after
deployment, choose **Manage app → menu → Reboot app → Reboot** and wait for startup.
For local use, copy those same paths into the existing project and restart Streamlit.
No dependencies, Azure settings or credentials change.
