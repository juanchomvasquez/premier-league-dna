## Evidence limits

Current reference rates are invented design hypotheses. Scores are independent model scores, not percentages of legends or calibrated historical similarity. Sequence coverage dimensions overlap. Ten sequences is a provisional display threshold, not a statistical guarantee. The generator models player actions rather than a complete possession-consistent football match. Coordinates use a normalized square and should not be described as pitch metres. Sequences crossing time boundaries need an explicit attribution policy before production use.
