# Position and reference design

These names are cultural design inspirations. All reference rates are invented;
they have not been calibrated against the named players' historical statistics.
The app compares synthetic players with independent invented archetypes, not
with verified versions of the legends.

| Position group | Design inspirations |
| --- | --- |
| Goalkeeper | Peter Schmeichel, Alisson, Ederson |
| Centre-back | John Terry, Nemanja Vidic, Rio Ferdinand |
| Full-back | Ashley Cole, Andy Robertson, Trent Alexander-Arnold |
| CDM | N'Golo Kante, Yaya Toure, Rodri |
| CM | Frank Lampard, Steven Gerrard, Paul Scholes |
| CAM | Mesut Ozil, Kevin De Bruyne, Cesc Fabregas |
| Winger | Cristiano Ronaldo, Eden Hazard, Mohamed Salah |
| Striker | Alan Shearer, Didier Drogba, Wayne Rooney |

The CDM, CM, CAM and winger groups are distinct analysis roles. Players can span
roles in football; this prototype assigns each fictional player one role for
clarity. Yaya Toure is intentionally a broader midfield design reference in the
CDM group. His inclusion should not be interpreted as an exclusive positional
classification. The winger references are provisional choices for this demo.

Comparisons operate within a position group. Scores across different role models
are not comparable, and profiles do not form percentages that add to 100.
