# Position and reference design

These names are cultural design inspirations. All reference rates are invented;
they have not been calibrated against the named players' historical statistics.
The app compares synthetic players with independent invented archetypes, not
with verified versions of the legends.

| Position group | Design inspirations |
| --- | --- |
| Goalkeeper | Peter Schmeichel, Petr Cech, Alisson |
| Centre-back | John Terry, Nemanja Vidic, Virgil van Dijk |
| Full-back | Ashley Cole, Kyle Walker, Trent Alexander-Arnold |
| CDM | N'Golo Kante, Claude Makelele, Rodri |
| CM | Frank Lampard, Steven Gerrard, Paul Scholes |
| CAM | Mesut Ozil, Kevin De Bruyne, Cesc Fabregas |
| Winger | Cristiano Ronaldo, Eden Hazard, Mohamed Salah |
| Striker | Alan Shearer, Didier Drogba, Thierry Henry, Wayne Rooney |

The CDM, CM, CAM and winger groups are distinct analysis roles. Players can span
roles in football; this prototype assigns each fictional player one role for
clarity. The references are simplified design choices, not exhaustive descriptions
of the named players. Strikers have four references; the interface supports a
variable number of profiles.

The Walker-inspired profile uses tackles, interceptions and carries; it does not
measure speed or recovery runs. The Cech-inspired profile emphasizes recorded
saves and claims without inferring command or positioning from tracking data.
The Henry-inspired profile combines shots, box arrivals and link-up passes within
the current five striker measurements. It does not yet represent carrying,
dribbling or finishing efficiency. These limitations prevent treating the
invented profiles as historical player models.

Comparisons operate within a position group. Scores across different role models
are not comparable, and profiles do not form percentages that add to 100.
