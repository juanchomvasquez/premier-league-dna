2. Open juanchomvasquez/premier-league-dna on GitHub, on the branch used by Streamlit.
3. Add file > Upload files. Drag app.py and the pl_dna, docs, tools and tests folders
   from INSIDE the extracted folder. Commit the changes. Existing matching files
   are replaced; other repository files stay in place. Do not erase the repository.

6. Inspect the calculated blend and source coverage first. Then click Generate
   legend story with Microsoft AI to make one potentially billable Azure request.
   Existing Azure secrets are reused. No secret file is included in this update.
